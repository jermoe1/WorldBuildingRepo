## HOW TO USE THIS FILE

This file has two layers: **Fundamentals** (the rules that govern all magic in this world) and **Traditions** (specific schools, disciplines, or cultural approaches to magic). Fundamentals must be established before Traditions can be properly defined. The tonal register of magic is set in WorldBuildingAssistant.md § Project Overview — all entries here should reflect that tone.
