## HOW TO USE THIS FILE

Establish naming rules **before** names accumulate. Every name in the Glossary should trace back to a convention here. When generating new names, consult this file first — consistency is the goal. Each culture or entity type gets its own convention block. The name pools at the bottom are for generation and reference.
