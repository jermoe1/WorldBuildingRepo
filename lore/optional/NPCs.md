## HOW TO USE THIS FILE

Each named character gets an entry. Player characters are not recorded here — this file is for the world's inhabitants. Keep the Current Status field updated as characters act in play. When a character dies or changes allegiance, update their entry and log the event in Timeline.md.

### Entry Template

```
### [Character Name]

**Role:** [What function does this character serve in the world — not in game terms, but narratively]

**Location:** [Where are they now? Cross-reference Geography.md]

**Faith:** [Cross-reference Gods.md]
```
