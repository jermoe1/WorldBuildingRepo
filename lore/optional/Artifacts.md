## HOW TO USE THIS FILE

"Artifacts" covers any named object with narrative or historical weight — not just magical items, but relics, weapons, documents, symbols of power. Keep the Current Location field updated. If an artifact changes hands, log it here and in Timeline.md.

### Entry Template

```
### [Artifact Name]
**Also Known As:** [Alternate names, names in other cultures]
**Type:** Weapon / Armor / Relic / Document / Symbol / Vessel / Other
**Origin:** [Who made this, when, and why? Cross-reference Timeline.md, Gods.md]
**Current Location:** [Where is it now? Cross-reference Geography.md]
**Current Possessor:** [Who holds it? Cross-reference NPCs.md, Factions.md]
**Status:** Intact / Damaged / Destroyed / Lost / Divided

**Description**
[What does this object look and feel like? Any sensory details that make it distinctive?]

**Properties & Capabilities**
[What does it do? Frame in narrative terms, not game mechanics. Cross-reference MagicSystem.md.]

**Cost or Condition**
[Does using or possessing this artifact carry a price? Physical, psychological, spiritual?]

**History**
[The artifact's known history — who has held it, what it has done, where it has been. Cross-reference Timeline.md.]

**Myths & Legends**
[What do people believe about this object, accurately or not?]

**Why It Matters**
[What would change if this artifact were found, destroyed, or used?]

**Factions Seeking It**
[Cross-reference Factions.md]

**Notes & Open Questions:**
```
