# RawImports.md
> Holding area for `Run import:` content that could not be confidently placed in another auxiliary file.
> Content here is unvetted and unconfirmed. Nothing in this file is canon.
> Cross-reference: meta/CLAUDE.md § Import Protocol.
>
> **Boundary with `RawIdeas.md`:** this file holds content that arrived through an import and failed classification. `RawIdeas.md` holds ideas with no external source — a thought or fragment that originated in conversation. Same "unvetted, not canon" status; different origin.

---

## HOW TO USE THIS FILE

This file is a temporary holding pen, not a permanent home. Content lands here when the `Run import:` protocol cannot confidently route it to another file. Every item here should be reviewed, resolved, and moved — or deliberately discarded. Run `Run review` periodically to surface stale items.

Each entry records what was imported, when, and what the open question is that prevented placement.
