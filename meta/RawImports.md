# RawImports.md
> Holding area for /import content that could not be confidently placed in another auxiliary file.
> Content here is unvetted and unconfirmed. Nothing in this file is canon.
> Cross-reference: WorldBuildingAssistant.md § Import Protocol.

---

## HOW TO USE THIS FILE

This file is a temporary holding pen, not a permanent home. Content lands here when the `/import` protocol cannot confidently route it to another file. Every item here should be reviewed, resolved, and moved — or deliberately discarded. Run `/review` periodically to surface stale items.

Each entry records what was imported, when, and what the open question is that prevented placement.
