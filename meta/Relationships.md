## HOW TO USE THIS FILE

This file captures the *connections* between entities rather than the entities themselves. It is the cross-reference layer. When a relationship is established in any other file, log it here. Read this file before writing any scene involving two or more factions, gods, or major NPCs.

Relationships are **directional when asymmetric** — note when one party views the relationship differently than the other.
