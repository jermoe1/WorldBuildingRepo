## HOW TO USE THIS FILE

One entry per confirmed plane. Primary planes formed directly from the Collision (Canon #11); lesser/blended planes form from the overlap of two primary elemental planes (Canon #23). Develop further via `Run agent:lore [plane name]`.

### Entry Template
```
## [Plane Name]
**Name Status:** ⚠️ NAME PENDING / Stable
**Design Anchor:** [Character or nature of this plane]
**Type:** Primary / Lesser (blended)
**Dominant Entities:** TBD
**Canon References:** [Entry numbers]
**Open Questions:**
- TBD
```
